\# Block 2 Exercise - SOLID Refactor



\## Core Deliverables

\* \*\*Refactored Code:\*\* C# scripts (`.cs`) updated to eliminate poor architectural patterns.

\* \*\*Documentation:\*\* Written reports (`.txt`) identifying violations and justifying the new design.



\## Task Resolution



The objective of this assignment was to identify and resolve various SOLID principle violations across five distinct C# codebases. 



To address this, the repository is organized into a group of folders (`Exercise\_1` through `Exercise\_5`), each containing the complete solution for a specific codebase. Inside every folder, the resolution is broken down into two components:



\* \*\*The Analysis:\*\* A documentation file detailing which principles (SRP, OCP, LSP, ISP, or DIP) were violated, exactly where the original design failed, and a technical justification for the new architecture.

\* \*\*The Solution:\*\* A refactored C# script that implements the necessary interfaces, class segregations, and abstractions to create a clean, extensible design without altering the original program behavior.
